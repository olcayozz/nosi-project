# Nosi Landing Page

Nosi şirketi için modern ve responsive bir web sitesi.

## Özellikler

- React 18 + TypeScript + Vite
- Tailwind CSS ile modern tasarım
- Responsive mobil uyumlu
- Hızlı ve optimize edilmiş

## Kurulum

```bash
npm install
npm run dev
```

## production Build

```bash
npm run build
npm run preview
```

## Docker

```bash
docker build -t nosi .
docker run -p 8080:8080 nosi
```

## Teknolojiler

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **Container:** Docker
